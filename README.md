# InterviewReady India

Mobile-friendly free interview practice for Indian fresh graduates.

## Run locally

Node.js 18+ required. Run `node server.mjs` and open http://localhost:3000.

## Hosting

Render web service: Node runtime, free plan, build command `echo ready`, start command `node server.mjs`.

This MVP offers five questions and basic rule-based feedback. It does not use paid AI APIs, process payments, or store user answers.
